### Playwright 全量结果说明(重要)

全量 5-project 跑出现与**阶段1首轮完全相同的失败模式**:`stored admin cookie → 401`(已直接 curl 验证),导致所有 admin-gated spec 集体失败。这是**已知的 E2E 基础设施问题(global-setup 捕获的 admin token 在长跑中被失效,详见 Report A §9),不是本次修复引入的回归**。

判定依据:
1. 失败的 spec 集合与阶段1首轮**逐一对应**(ai-config/article-detail/articles-enhanced/rbac-ADMIN/review/search/settings/wechat-rss),无新增失败类型。
2. 我修复的 9 个 P0/P1 全部通过 vitest(720/720)+ build,且每个修复都配套了单测(route/service 层)。
3. 关键权限路径(sync owner 隔离、SyncRecord 404、USER 建卡拒绝、A/B 隔离)由 vitest 在 mocked 层覆盖;E2E 层因 fixture 污染无法独立验证,改用「fresh fixture 重跑相关 spec」补充(见上)。

### 剩余 E2E 基础设施债(遗留,非本次修复范围)

- **P2-1(Report A):admin fixture 健壮性**。建议:global-setup 用持久 Max-Age token 而非 session cookie;或 spec 内 beforeAll 重新登录;dev server 关闭 hot-reload 密钥轮换。**这是 E2E 可信度的根因,建议下一轮单独修。**
