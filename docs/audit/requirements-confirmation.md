## 2. 项目定位

项目是面向申论学习的素材采集、文章学习、AI 评估、素材卡生成、复习和 IMA 同步系统。

核心闭环：

`采集文章 -> AI 评估 -> 管理员审核 -> 用户学习文章 -> VERIFIED_USER 生成私有素材卡 -> 复习 -> 同步个人 IMA`

技术栈保留：

- Next.js / React / TypeScript
- Prisma / PostgreSQL
- Tailwind CSS / shadcn 风格本地组件
- Vitest / Playwright

UI 改进和 UI 组件库系统化改造置后，不进入当前第一批主线。

## 3. 角色与权限

系统角色：

- `USER`
- `VERIFIED_USER`
- `ADMIN`

### USER

- 可注册登录。
- 可查看审核通过的公共文章。
- 可阅读、收藏文章。
- 可复习自己收藏的文章。
- 不可 AI 生成素材卡。
- 不可配置个人 AI。
- 不可配置或同步 IMA。
- 不可访问后台。

### VERIFIED_USER

- 拥有 USER 的全部学习能力。
- 可配置自己的 AI key。
- 可从已审核文章生成自己的私有素材卡。
- 可复习自己的素材卡。
- 可配置自己的 IMA target。
- 可同步“自己可见的文章 + 自己的素材卡”到自己的 IMA。
- 不可访问后台。

### ADMIN

- 可访问后台。
- 可管理用户、文章、来源、WeWe RSS、日志、任务、配置、用户私有资产。
- 可查看全局数据用于管理。
- 对关键写操作必须写审计日志。
- 不能禁用、降级或删除最后一个 ADMIN。
- ADMIN 自己使用 IMA 时也必须配置自己的 IMA target，不使用系统 env fallback。

## 4. 用户与认证

- 前台登录入口为 `/login`。
- 后台登录入口为 `/admin/login`。
- `/admin/login` 只接受 ADMIN 登录；USER/VERIFIED_USER 即使密码正确也提示无后台权限。
- `/login` 提供注册入口。
- 无邀请码注册为 USER。
- 有有效邀请码注册为 VERIFIED_USER。
- USER 可在设置/账号页输入邀请码升级为 VERIFIED_USER。
- 邀请码一次性使用。
- 注册成功后自动登录。
- 用户禁用后：
  - 保留全部数据。
  - 禁止继续登录和操作。
  - 已有 session 必须立即失效。
  - 登录或访问受保护页时明确提示账号已禁用，请联系管理员。

## 5. 路由与前端信息架构

### 登录态路由

- `/`：登录后角色化首页；未登录直接跳 `/login`。
- `/articles`：核心文章页，包含 `全部 / 推荐 / 收藏` 三个 Tab。
- `/cards`：登录后私有素材卡列表。
- `/search`：登录后搜索页。
- `/review`：登录后复习页。
- `/settings`：登录后设置页。
- `/integrations/wewe-rss`：公开可见的 WeWe RSS 权限说明页。
- `/admin/*`：ADMIN 后台。

### 前台旧路由

后续删除，不做兼容重定向：

- `/discover`
- `/explore`
- `/my-articles`

`/articles` 承担文章相关入口：

- `全部`：全量已审核文章库。
- `推荐`：管理员人工精选/置顶，不做个性化算法。
- `收藏`：用户收藏管理和继续阅读。

### 导航展示

前台导航按能力显示：

- 未登录：只显示登录入口和允许公开访问的说明页。
- USER：文章、复习、设置。
- VERIFIED_USER：文章、素材卡、复习、设置。
- ADMIN：前台学习入口 + 后台入口。

首页快捷入口与顶部/底部导航保持一致，不展示当前角色不可用能力。

### 移动端

- 不做独立 H5 项目。
- 同一个 Next.js 前端做响应式布局。
- 前台移动端使用底部 Tab：
  - USER：文章 / 复习 / 设置
  - VERIFIED_USER：文章 / 素材卡 / 复习 / 设置
  - ADMIN：后台入口不挤占底部主学习导航。
- 后台移动端只要求基本可用：能登录、查看、不横向爆版；复杂表格和批量操作以桌面为主。
- 本阶段不做 PWA、离线缓存、推送或安装到桌面。

## 6. 数据归属与可见性

公共文章：

- 审核通过的文章是公共学习材料。
- 普通用户只看 `adminReviewStatus=approved` 且可见的文章。

用户私有状态：

- 阅读状态、收藏状态、忽略状态、文章复习状态均归属用户个人。
- `ContentItem` 上全局 `read/bookmarked/ignored` 字段不能作为长期方案。

素材卡：

- 素材卡始终是用户私有资产。
- Owner 可查看、编辑、软删除/归档自己的素材卡。
- ADMIN 可查看和管理任意素材卡。
- 其他用户访问别人的素材卡详情返回 404，隐藏资源是否存在。
- 素材卡默认不做用户间共享，不做公开素材库。

归档/软删除：

- 素材卡删除语义是软删除/归档。
- 归档卡片只在归档箱可见。
- 默认列表、搜索、复习、IMA 同步排除归档卡片。
- 恢复归档卡片时完整保留标签、复习状态、掌握状态、同步记录。
- 归档不主动删除外部 IMA 中已同步的副本。

重复生成：

- 同一用户对同一文章默认不重复生成多张卡。
- 已有卡片时复用/打开。
- 显式“重新生成”才覆盖旧内容。
- 重新生成直接覆盖旧内容，但必须二次确认。
- 重新生成后重置复习状态，保留 owner 和关联文章。

## 7. 文章采集、AI 评估与审核

所有入库文章统一走：

`采集/导入 -> AI 评估 -> 管理员人工审核 -> approved 后进入公共学习材料`

- 覆盖 WeWe RSS、手动来源、外部 fallback、导入等所有入库来源。
- 手动导入也不能绕过审核。
- AI reject 后 ADMIN 可强制 approve。
- 强制 approve 必须填写原因并写审计日志。
- ADMIN 人工 reject/downlist 语义是下架，不删除用户私有卡。
- 下架文章：
  - 不出现在普通搜索结果。
  - 不作为新学习入口。
  - 禁止新生成素材卡。
  - 已收藏过的用户仍可在历史收藏/复习入口只读查看，并显示已下架标记。
  - 已有用户私有素材卡保留，并标记来源/文章已下架。
- 同一来源文章首次入库后，如果再次采集到内容变化，忽略后续正文变化，不自动更新公共文章内容。

## 8. AI 与 IMA

个人 AI：

- VERIFIED_USER/ADMIN 生成私有素材卡必须使用自己的 AI key。
- 不允许 fallback 到全局/env AI key。
- 缺少个人 AI 配置时禁止生成，明确引导去配置。
- 个人 AI 配置入口只对 VERIFIED_USER/ADMIN 可见。

IMA：

- VERIFIED_USER/ADMIN 可使用 IMA。
- USER 没有 IMA 配置和同步入口。
- 每个用户，包括 ADMIN，必须配置自己的 IMA target。
- 不允许 sync fallback 到 env IMA 配置。
- IMA 同步范围为：自己可见的文章 + 自己的素材卡。

## 9. 后台、审计与危险操作

ADMIN 可管理：

- 用户与角色
- 用户启用/禁用
- 文章审核/精选/下架
- 来源与 WeWe RSS
- 用户私有资产
- 日志、任务、备份、清理

审计日志必须覆盖关键写操作：

- 用户管理
- 角色/状态变更
- 密码重置
- 审核、强制通过、下架
- 删除/清理/归档
- 修改用户资产
- 集成配置变更

审计内容：

- 操作者
- 动作
- 目标类型/ID
- 变更摘要
- 原因/备注
- 时间
- 敏感字段脱敏

所有密钥类都必须脱敏：

- AI key
- IMA token/key
- cookie
- Authorization
- webhook secret
- 其他 secret

危险操作：

- 后台删除、批量清理、下架等危险操作必须预览 + 二次确认。
- 批量/破坏性操作默认 dry-run。
- 本阶段不提供用户账号删除，用禁用代替。

## 10. 前端体验要求

视觉方向：

- 前台是工具型学习台。
- 信息密度适中。
- 前台文章列表和素材卡列表默认舒适卡片。
- 后台可保持表格和高密度操作。

空状态：

- 每个空状态都告诉用户下一步该做什么。
- 文章为空时提示联系管理员处理。
- `/cards` 无卡片：引导去已审核文章生成素材卡。
- `/review` 无收藏/无卡片：引导去文章库收藏或生成。
- 搜索无结果：提示换关键词/清筛选。
- 后台无待审核：提示暂无待审核，不乱引导。

搜索：

- `/search` 登录后可用。
- USER 搜索已审核文章。
- VERIFIED_USER/ADMIN 搜索文章 + 自己的素材卡。
- 结果用“文章 / 我的素材卡”Tab 或分组。

复习：

- `/review` 用“收藏文章 / 素材卡”Tab。
- USER 只显示收藏文章。
- VERIFIED_USER/ADMIN 显示收藏文章和素材卡。
- 文章收藏管理在 `/articles` 收藏 Tab；复习动作在 `/review`。

文章详情：

- USER：阅读、收藏、加入复习等学习操作。
- VERIFIED_USER：在 USER 操作基础上显示生成素材卡/查看已生成素材卡。
- ADMIN：前台文章详情不做审核；审核只在后台完成。
